# Moments

A private two-person memory album: flip-through polaroids, a timeline of days, and glowing orbs for milestones. No feed, no audience — just the two of you.

Live: [moments-nine-navy.vercel.app](https://moments-nine-navy.vercel.app)

## What’s in it

- **Memories** — polaroid-style photos and notes
- **Timeline** — days laid out in sequence
- **Milestones** — soft orbs for the moments that matter
- **Google sign-in** — private to the people you invite

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + Framer Motion
- Firebase Auth, Firestore, and Storage

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). You will need Firebase project credentials in the environment (Auth, Firestore, and Storage) before sign-in works.
